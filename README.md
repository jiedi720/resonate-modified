# 学习目录功能更新

## 功能说明

- 在 **Library settings（媒体库设置）** 中选择学习目录，例如 `Music/Korean/`。
- 媒体库仅收录所选目录及其子目录中的音频文件。
- 通过 Android 系统文件夹选择器授权，并保存目录 URI 与持久化访问权限；重启应用后仍然保留。
- 可以更换目录或清除选择；清除后恢复扫描整个媒体库。
- 原有排除目录设置仍然有效。

## 支持范围

目前仅支持 Android 内部共享存储的 `primary` 卷。选择其他存储卷或文档提供方时，功能暂不支持。

## 使用步骤

1. 打开 Resonate 的媒体库设置。
2. 选择学习目录并确认系统文件夹授权。
3. 重新扫描媒体库，使目录筛选生效。

> 注意：当前实现通过 MediaStore 查询音频后，再按所选目录路径进行筛选；并非只查询该目录。
